## Who Should Take This Exam?

- **ERP & AL Developers** who design, code, test, and maintain custom solutions for Business Central.
- **Technical Consultants** extending standard features via AL table extensions, page extensions, and codeunits.
- **Integration Engineers** linking Business Central to external systems using REST APIs, OData web services, and Azure services.
